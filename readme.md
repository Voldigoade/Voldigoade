## Featured project

### [OpenBioFigure](https://github.com/Voldigoade/openbiofigure)

A local-first, browser-based editor for scientific vector figures with built-in asset provenance, licence tracking, attribution, and reproducible exports.

**Stack:** TypeScript · React · Vite · Tauri · Vitest · Playwright

[Live app](https://voldigoade.github.io/openbiofigure/) · [Source](https://github.com/Voldigoade/openbiofigure) · [Documentation](https://github.com/Voldigoade/openbiofigure/tree/main/docs) · [Issues](https://github.com/Voldigoade/openbiofigure/issues)
